# Kingdom Dilemma

A narrative decision-making game inspired by medieval history and interactive storylets.

Players take the role of a king ruling through crisis, where every decision involves tradeoffs between survival, authority, and public trust. Through plague outbreaks, famine, religious conflict, and war, players must keep the kingdom stable long enough to survive the winter.

## Core Concept

Kingdom Dilemma is inspired by games like Reigns and uses a branch-and-bottleneck storylet structure.

Each scenario presents a dilemma with three choices

Each choice affects kingdom resources:

- Food  
- Army  
- Trust  
- Faith (secondary modifier)

There are no simple right-or-wrong answers. Every decision has both gains and costs.

## Learning Goals

This project explores how interactive narrative can support learning through decision-making.

Players engage with:

- Medieval history and governance  
- Resource tradeoffs and crisis management  
- Cause-and-effect relationships in political systems  
- Historical facts embedded as reflective feedback after choices

The project combines gameplay with short “Medieval Facts” to connect player decisions to historical context.

## Win / Lose Conditions

### Victory
- Survive 10 turns

### Failure
- Food reaches 0 → Famine  
- Trust reaches 0 → Revolt  
- Army reaches 0 → Military Collapse
